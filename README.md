## Algorithms

### Insertion Sort
Basic sorting algorithm.

Time Complexity:
- Best: O(n)
- Average: O(n²)
- Worst: O(n²)

### Merge Sort
Advanced divide-and-conquer sorting.

Time Complexity:
- O(n log n)

### Binary Search
Searches in sorted arrays.

Time Complexity:
- O(log n)
